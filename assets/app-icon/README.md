# Bytehroom app icon

The official app icon is the seven-hexagon Bytehroom mark in `#0097B2` on transparency. The full wordmark lives at
`assets/brand/bytehroom-logo.png`.

The technical filenames and application id still contain `lightcraft` for compatibility with the inherited build,
packaging and user-data paths. Their artwork is Bytehroom's.

`lightcraft.svg` is the canonical vector icon. PNG, ICO and ICNS files are generated from that geometry.
See `LICENSE.txt` and `assets/brand/LICENSE-brand.txt` for the brand terms.
